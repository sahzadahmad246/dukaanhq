# DukaanHQ

DukaanHQ is a mobile-first multi-tenant SaaS for retail shops.

## Stack
- Next.js
- Bun
- Supabase Auth
- Google OAuth
- Cloudinary
- Resend

## Getting Started

```bash
bun install
bun dev
```

Open `http://localhost:3000`

## Setup

See [SETUP.md](./SETUP.md) for:
